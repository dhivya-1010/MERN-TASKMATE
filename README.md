# To-Do App

A simple and organized To-Do application that allows users to manage their tasks in one place. Users can register, log in, create and update todos, and view tasks sorted by priority and due date.

## Features

- **User Registration:** Create an account to access the application.
- **User Login:** Log in securely using your credentials.
- **Dashboard:** View all your todos in one place.
- **Add Todos:** Create new tasks with relevant details.
- **Edit Todos:** Modify existing todos whenever needed.
- **View Todos:** Browse the complete list of tasks.
- **Task Sorting:** Organize todos based on priority and due date.

## Todo Details

Each todo can include the following details:

- Task Title
- Description
- Priority
- Due Date
- Status
